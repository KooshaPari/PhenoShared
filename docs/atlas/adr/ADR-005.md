# ADR-005 — Applet is not repository or service

**Status:** Proposed in this package; not a fabricated accepted human decision.  
**Source:** INT-001 and carried prior constraints.  
**Date:** 2026-09-15.

## Context

Recursive federation can otherwise recreate fragmentation.

## Decision proposal

Use semantic applet contracts with direct/local lowering by default.

## Alternatives considered

Every applet as microrepo/microservice; no reusable boundaries.

## Consequences and verification

Actual isolation/network needs still justify separate runtimes. Bind the decision to an actual subject/owner and verify through the associated requirements, work and native evidence. A document's existence is not a product implementation or governance transition.

## Reconsideration trigger

Reconsider individual boundaries from consumers/security/releases.
