## Definitions

- **LOC** = logical line count = number of `\n` bytes, plus 1 when a non-empty file does not end in a newline. `wc -l` reports one less for those files; the stricter definition is used so the 350/500 gate cannot undercount.
- **Ownership** = a file belongs to the deepest tracked `Cargo.toml` directory containing it. Nested packages are therefore not double counted, and a wrapper crate is not credited with its children's code. The `LOC`/`files`/`tests` columns are tree totals, not own totals.
- **tests** = test declarations, language by language: Rust `#[test]` / `#[<crate>::test]` attributes, Python `def test_`, Go `func Test`, JS/TS `it(` / `test(` at line start. This counts declarations, not a verified passing suite.
- **kind** = workspace membership: `member` (listed in the root `[workspace] members`), `excluded`, `sub-workspace` (declares its own `[workspace]`), `non-member` (has `[package]`, not a member), `manifest-only`, `workspace-root`. Flavour is `lib` / `bin` / `lib+bin` / `meta` from the `[lib]` and `[[bin]]` tables.
- **docs** = tracked `.md`/`.mdx` files inside the package tree.
- **os_cfg** = distinct `target_os = "..."` values appearing in the package (`-` when the package is platform-independent).
- **last** = newest author date (`%aI`) across the package's files.
- **role** = `[package] description`; else the first prose line of the package `README.md`; else inferred from the package name. Inferred roles are prefixed `~`.
