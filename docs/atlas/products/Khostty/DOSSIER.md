## 5. Controlled pilot

Run a terminal conformance/workload corpus: Unicode, wide/combining characters, resize/reflow, alternate screen, bracketed paste, IME, modifiers, high output, screen-reader/keyboard navigation and embedded use where promised. Compare both correctness and perceived/recorded latency at the same workload.

Use fixed versioned inputs and independent outcome oracles. Run matched conditions to isolate mechanisms and a separate idiomatic implementation to compare practical products. Retain failed attempts, intervention logs and infrastructure outcomes. Assign confidence intervals or explicit uncertainty; do not infer a universal winner from one run.

Failure and negative-control cases:

- Input lost on focus transition
- Escape sequence corrupts state
- Resize loses content
- Paste executes unexpectedly
- Renderer leaks memory under long output
- Embedding changes permission or lifecycle behavior
