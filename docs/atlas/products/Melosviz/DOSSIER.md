## 5. Controlled pilot

Use the same authorized music excerpt to import, analyze, play/synchronize, edit a scene, render/export and reopen. Then replace the track, change timing, use a new preset, disable a backend and recover. Compare actual output and editing effort, not only generation latency.

Use fixed versioned inputs and independent outcome oracles. Run matched conditions to isolate mechanisms and a separate idiomatic implementation to compare practical products. Retain failed attempts, intervention logs and infrastructure outcomes. Assign confidence intervals or explicit uncertainty; do not infer a universal winner from one run.

Failure and negative-control cases:

- Stub backend produces plausible but wrong output
- A/V drift
- Render cancelled but resources remain
- Export missing codec/frames
- Preset version cannot reopen
- Private source media published unintentionally
