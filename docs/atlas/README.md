# Phenotype Atlas, Assurance and Semantic Compression Program

A repository-ready, self-contained `docs/` package for the latest portfolio plan: explanatory codebase atlases, granular specifications, independently measured QA, dissatisfaction, dependency-backed simplification, recursive applets, comparative pilots and current viable products.

Read [START-HERE.md](START-HERE.md). Coordinators use [the master prompt](prompts/MASTER-COORDINATOR.md); product pairs use the specific dossier in [the roster](portfolio/ROSTER.md). Tracera's ten-seat allocation is in [the team contract](prompts/TRACERA-TEN-SEATS.md). The methodology is in [SPECIFICATION.md](SPECIFICATION.md), [HLD.md](HLD.md), [ALD.md](ALD.md) and [LLD.md](LLD.md).

This is an additive implementation/verification program, not a new registry, a migration order or a current certification of the portfolio. No source repositories, hosted services or engine states were changed while creating it. Pilot plans contain no measured results. Original contextual archives are retained separately with hashes. The latest visible plan's 30-item cohort is provisional; the original 62-ID audit is preserved as historical input.

The core objective is less custom maintenance, fewer unsupported claims, and useful installed products—not more repositories, generated prose, commits or test-count padding. Tracera can adopt the same records while product teams continue independently.

The schemas and reference record checker provide structural/semantic consistency checks only. They do not authenticate producers, approve work, verify remote signatures, execute product tests or establish every acceptance criterion. See [VALIDATION_REPORT.md](VALIDATION_REPORT.md).

## Included scope

23 product/lab dossiers and planned pilots; nine supporting/foundation/conditional capability dossiers; 110 proposed program requirements; 11 provisional specification bundles; 13 proposed ADRs; 120 work packages; 48 entity types and 50 relation types; ten interchange schemas; a 33-page PDF reading edition; and 175 passing reference-tooling tests. These counts describe this package, not completed native product work.
