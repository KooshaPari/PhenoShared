## Convention

Every WBS uses the same 8-prefix branch taxonomy:

- `feat/` — new feature
- `fix/` — bug fix
- `chore/` — tooling / config
- `docs/` — docs only
- `test/` — test infrastructure
- `refactor/` — code restructuring (no behavior change)
- `perf/` — performance optimization
- `build/` — build system / CI
