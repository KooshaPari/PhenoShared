## What's NEW in v0.12 (delta from v0.11)

### 1. Tracera persistent trace integration

- `pheno/trace_store/tracera.py` — TraceraAdapter with `append_event`,
  `query`, `flush`, `enqueue_event`, `health`.
- `pheno/trace_store/protocols.py` — `TraceEvent` + `TraceStoreAdapter` Protocol.
- `traces/tracera_bridge.py` — fail-soft dual-write bridge (JSONL +
  Tracera, never blocks ingest).

- `config/pheno_runtime.yaml` — schema for runtime config.
- `pheno/runtime_config.py` — typed lazy loader.
- `docs/integrations/tracera-api.md` — API reference.
- `bench/results/tracera_integration_test.json` — integration artifact.

### 2. Hermetic test subset

- `tests/hermetic_subset.txt` — 37 curated hermetic test paths.
- `scripts/run_hermetic_tests.sh` — bash wrapper (default subset,
  --full, --collect modes).
- `tests/_harness.py` — `skipif_no_docker`, `skipif_no_mlx`,
  `skipif_no_harbor`, `skipif_insecure_default` markers.
- `docs/guides/hermetic-testing.md` — what counts as hermetic.
- 264 tests, 42s wall time, 0 external deps required.

### 3. SOTA cron UTC flake fix

- `tests/test_sota_snapshot_chain.py::test_sota_chain_has_no_gap_in_last_5_days`
  now anchors the reference to the latest snapshot date instead of
  wall clock. The known flake (failure window ~16:00-00:00 UTC) is
  gone.

### 4. Runtime config schema (YAML + env fallback)

- `config/pheno_runtime.yaml` — schema_version=1.
- `pheno/runtime_config.py` — TraceraConfig, EvidenceConfig,
  TraceBridgesConfig dataclasses; lru_cache'd loader.
- YAML wins over env when YAML has a value; env is fallback when YAML
  is null.

### 5. Desktop execution policy hardening

- `scripts/run_desktop_agentic_fixture.py` — `_require_live_execution_policy()` fail-closed.
- `scripts/run_desktop_lane_eval.py` — same.
- `tests/test_desktop_execution_policy.py` — verifies a window ID
  cannot override a paused contract.

import ast, os
from pathlib import Path
DIRS = ['pheno', 'bench', 'eval', 'verifier', 'traces']
total = missing = 0
for d in DIRS:
    for root, dirs, files in os.walk(d):
        dirs[:] = [x for x in dirs if x not in ('__pycache__', '.venv', 'node_modules', 'worktrees')]
        for f in files:
            if not f.endswith('.py'): continue
            try:
                tree = ast.parse(Path(root, f).read_text(encoding='utf-8'))
            except: continue
            for node in ast.walk(tree):
                if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
                    if node.name.startswith('_'): continue
                    total += 1
                    if not ast.get_docstring(node): missing += 1
print(f'{100*(total-missing)/total:.1f}% ({total-missing}/{total}, {missing} missing)')
