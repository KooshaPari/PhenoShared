## What is "harbor" + "MCP" in pheno-harness context

- **Harbor 0.1.42**: the **content-addressed local evidence store** in
  `harbor_cli/` (PowerShell scripts). The scripts (`run_tbench_local.ps1`,
  `run_agent_eval.ps1`, etc.) drive terminal-bench evaluations
  against the local harbor URL. harbor 0.1.42 is the version last
  audited production-ready on 2026-08-08.
- **MCP**: in this v0.13 plan, "MCP" is the **Model Context Protocol
  audit task family** (tasks 89-95 last bullet). It refers to the
  consumer-side freshness check used by
  `traces/ingest.py` `TraceraAdapter.flush()` and the bench CLI
  integration. There is no MCP server code in pheno-harness — the
  task family audits MCP *consumer* hooks.

Both runbook topics are scoped to v0.13 Phase 7 audit-only.
