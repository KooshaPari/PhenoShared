## Audit method

```sh
# 1. List the installed scripts
ls -la ~/.forge/bin/forge-{watchdog,net-heal,proc-reap}.sh

# 2. Validate plists
plutil -lint ~/Library/LaunchAgents/com.phenoforge.forge-{watchdog,net-heal,proc-reap}.plist

# 3. Verify repo == host (sha256)
shasum -a 256 ~/.forge/bin/forge-{watchdog,net-heal,proc-reap}.sh \
              scripts/forge/forge-{watchdog,net-heal,proc-reap}.sh

# 4. Force-fire all 3
UID_VAL=$(id -u)
for label in forge-watchdog forge-net-heal forge-proc-reap; do
  launchctl kickstart -k "gui/${UID_VAL}/com.phenoforge.${label}"
done

# 5. Wait + tail logs
sleep 5
tail -10 ~/.pheno-harness/logs/com.phenoforge.forge-{watchdog,net-heal,proc-reap}.log
```

is preserved at both `scripts/forge/` and `~/.forge/bin/` as a
forwarding wrapper (`exec forge-proc-reap.sh "$@"`) so any external
callers continue to work.
