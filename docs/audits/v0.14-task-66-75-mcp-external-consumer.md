## What "MCP" means in the v0.14 plan

MCP = **Model Context Protocol**. In v0.14 Phase 5, this task family
audits **external MCP consumers** of the Tracera + AgilePlus
services: any external client that talks to our MCP endpoints.

The pheno-harness Python sources do not implement an MCP server;
they consume MCP via `traces/tracera_bridge.py` and
`beads/agileplus_adapter/`. Auditing external MCP consumers means
confirming that no third-party tool is talking to our services in
unintended ways.
