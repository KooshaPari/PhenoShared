## Migration procedure (consolidated)

```sh
# 1. Source the deprecation flag (task 74).
source ~/.pheno-harness/env.sh

# 2. Verify the cockpit history (task 73 prep).
.venv/bin/python scripts/cockpit_migrator.py --verify

# 3. Migrate 50 beads at a time (task 74).
bash scripts/migrate_50_beads.sh

# 4. Re-verify (task 74 closeout).
.venv/bin/python scripts/cockpit_migrator.py --verify

# 5. Archive the cockpit history (task 70).
mv /path/to/phenotype-dag/beads.jsonl /path/to/beads.jsonl.archive.$(date +%Y%m%d)

# 6. Render the deprecation banner (task 73).
#    Edit the cockpit HTML to display:
#    <aside class="deprecation-banner">
#      ⚠️ This dashboard is deprecated as of v0.13.0.
#      Migrate to AgilePlus + Tracera — see docs/cockpit/deprecation-ladder.md.
#    </aside>
```
