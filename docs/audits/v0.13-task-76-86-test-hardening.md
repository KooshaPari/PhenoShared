Covers:
1. `active_environment()` returns a known env for unknown values
2. `KNOWN_ENVIRONMENTS` includes `dev`/`staging`/`prod`
3. `DEFAULT_ENVIRONMENT` is `dev`
4. `TraceBridgesConfig.from_raw({})` builds with sane defaults
5. Unknown top-level keys are ignored (no error)
6. `TRACERA_DUAL_WRITE` (legacy) sets `dual_write`
7. `TRACERA_DUAL_WRITE_DEFAULT` (new) honored
8. `load_config()` with missing file: implementation-defined
9. `load_config()` with empty file: implementation-defined
10. `load_config()` with malformed YAML raises
11. `TraceBridgesConfig` has `dual_write_sample_rate` ∈ [0, 1]

### `tests/test_tracera_bridge_thread_safety.py` (4 tests)

Covers:
1. Concurrent emit (10 threads × 5 emits) → `emitted_total == 50`
2. Public counters never go negative under race (20 × 50 = 1000 events)
3. `emitted_total` is monotonically non-decreasing across two emit runs
4. `BridgeMetrics` is a frozen dataclass (immutable)
