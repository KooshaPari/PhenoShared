## Notes on the 3 forge-* placeholders

The 3 `forge-watchdog`, `forge-net-heal`, `forge-proc-reap` plists
run `/usr/bin/true` as a no-op placeholder. These are **intentional
stubs** — the actual agent logic lives in `~/.forge/bin/forge-compact.py`
(SQLite DB compactor), not in shell scripts. Once the watchdog / net-heal /
proc-reap scripts are written, the plists can be updated to invoke them.
