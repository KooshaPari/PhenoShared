# Inherited evidence is not a fresh audit

The original contextual ZIPs are preserved byte-for-byte and fingerprinted in `input-manifest.json`. They are background evidence, not six concurrent instruction sets. Their dates, assumptions, permissions, names and definitions can conflict. The controlling entrypoint is the new `START-HERE.md`, the subject's accepted decisions, and the exact current human scope.

`prior-62-assessments.json` preserves the earlier audit's own limitations. It is a historical 62-ID dataset, not the current 52-ish census. The planning cohort in this package comes from the latest visible conversation. No GitHub mutation or fresh full-tree inspection was performed while packaging.

Earlier findings about false-green checks, unavailable dependencies, duplicated source owners and empty release assets are revalidation candidates. A fixed current head must supersede an older finding with evidence; a renamed path does not erase the finding or prove it fixed.

The old fabric package is included for deep compute/data/I/O intent only. Its original factual assumptions about codecs, hardware, platform support or migration mechanisms must be reverified before implementation. Do not copy its working product name or domain-specific schemas into unrelated repos.
