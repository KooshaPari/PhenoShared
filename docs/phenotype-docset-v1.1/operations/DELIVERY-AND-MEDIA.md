# CVP, publication and authentic media

The current viable product is the coherent usable version of the accepted current horizon, not a scope-cutting trick. Domain feature implementation and delivery tooling are separate work, but required tooling code must be completed too. A product-dependent proof remains blocked until the product exists; a working canary proves only the pipeline.

For GUI products, qualify a real installed application outside the source tree. For macOS, the actual app bundle must launch through normal OS behavior and the intended discovery path. For CLI/library products, qualify clean packages and real consumers. Labs produce actual reproducible experiment bundles. Historical references receive custody, not fake apps.

The release chain binds source and locked inputs to build, native tests, package contents, notices/SBOM/provenance, signing where required, clean install/update/rollback and authorized publication. Release titles and attestations do not prove executable assets exist. Verify other distribution channels before concluding absent assets mean no distribution.

Carry forward the requested domain architecture as accepted intent: phenotype.space landing/docs composition through the generic landing consumer and Vercel; subject docs through PhenoDocs and Pages where applicable; product-level hosted deployments mapped under pheno.studio. This package does not verify or change DNS/Vercel/Pages. Target-specific base paths/canonical URLs can produce distinct bytes, so keep source identity and per-output digests separate.

Capture actual product journeys through qualified phenotype-journeys adapters in private nondisruptive environments. Browser containers, Linux virtual displays, dedicated Windows VMs, macOS native sessions and device/emulator leases have different capabilities. Do not assume native macOS/Adobe work can run in an arbitrary Linux container. Preserve raw evidence, failed runs, profiles, logs and actual assertions; publish sanitized derivatives only.

Use free/OSS tools and installed licensed Blender/Adobe facilities as appropriate for authored 2D/2.5D/3D, static or animated assets. Preserve editable sources, inputs, rights, tool versions and export recipes. Do not redistribute font binaries. Branding/concept visuals are not evidence of implemented UI. CLI-only products still need clean machine-level branding and VHS demonstrations; logos/ANSI must not corrupt machine-readable stdout.
