## 5. Controlled pilot

On the same Apple hardware, load the same supported model/quantization and run cold/warm request sets at declared concurrency. Measure quality on fixed prompts, latency distributions and memory. Cancel, unload, restart and create controlled memory pressure; test the actual install recipe on a clean environment.

Use fixed versioned inputs and independent outcome oracles. Run matched conditions to isolate mechanisms and a separate idiomatic implementation to compare practical products. Retain failed attempts, intervention logs and infrastructure outcomes. Assign confidence intervals or explicit uncertainty; do not infer a universal winner from one run.

Failure and negative-control cases:

- OOM returns corrupted output
- Cancelled request persists indefinitely
- Wrong cache reuse
- Model unload leaks residency
- Version injection fails silently
- Benchmark compares unequal models
