# Installation Guide

> TODO: Document installation options for phenodocs.

## Package Managers

### npm

```bash
npm install phenodocs
```

### pnpm

```bash
pnpm add phenodocs
```

### yarn

```bash
yarn add phenodocs
```

## From Source

```bash
git clone https://github.com/phenotype-org/phenodocs
cd phenodocs
pnpm install
```
