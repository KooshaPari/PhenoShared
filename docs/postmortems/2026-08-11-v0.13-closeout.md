## Lessons learned

1. **Disk pressure mitigation**: 100% full disk blocked `mkdtemp` on
   several occasions; leveraged the auto-commit daemon to recover and
   staged smaller commits when ENOSPC struck. Live evidence:
   `forge-watchdog` log line `disk=100%, mem=99%, procs=616`.
2. **Backward-compat regression caught early**: when adding
   `TRACERA_DUAL_WRITE_DEFAULT`, broke `TRACERA_DUAL_WRITE`-using
   tests. Fixed in commit `21072e56` by honoring both env vars
   (legacy preserved).
3. **Lazy import vs. testability tension**: AgilePlusBeadStore was
   imported inside `cockpit_migrator.py` functions; tests had to
   patch the symbol at the import path, not the function module.
   Refactored to take a `store` argument and import at call site.
4. **launchctl OnDemand YAML block**: `launchctl list "<label>"`
   returns a multi-line YAML block for OnDemand agents, not the usual
   `PID EXIT_CODE LABEL` line. `forge_status.sh` detects the leading
   `{` and tags fields as `(on demand)`.
5. **In-repo scope expansion**: user explicitly authorized in-repo
   polish (more docs, more tests, more scripts). This unlocked the
   cockpit deprecation ladder, forge_status.sh, test_v013_hermetic.sh.
