# dagctl

DAG control CLI binary for the Phenotype fleet.

**Version:** 3.3.1
**Source:** [KooshaPari/phenodag](https://github.com/KooshaPari/phenodag)

## Usage

```bash
chmod +x dagctl
./dagctl --help
```

## Build from Source

```bash
git clone git@github.com:KooshaPari/phenodag.git
cd phenodag
go build -o dagctl .
```
