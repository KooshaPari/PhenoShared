## Reproducibility contract

Every run must emit a manifest that includes:

1. `engine` (sglang | vllm | llama.cpp)
2. `model` (HF repo + rev)
3. `batch_size` (1 or 4)
4. `n_tasks` (16 for the fixture)
5. Per-task: `{ttft_ms, itl_ms_p50, itl_ms_p95, decode_tok_s, completion, error}`
6. Summary: `{ttft_ms_p50, ttft_ms_p95, decode_tok_s_p50, decode_tok_s_p95, n_tasks_ok, n_tasks_error}`
7. `gpu`: `{vram_peak_gb, vram_avg_gb, gpu_util_p50, gpu_util_p95}`
8. `spec_dec` results: `{none, n_gram, eagle2, mtp}` per method
9. `commit_hash`: pheno-harness HEAD when the run was executed
10. `environment`: python version, torch version, sglang/vllm version, cuda driver version
11. `cost`: total USD (always $0 for local runs)

## Spec-dec acceptance-ratio note

The OpenAI-compatible interface does not surface per-spec-dec acceptance ratio
engine-side. We measure indirectly via decode speed uplift (none baseline vs
each method), and assume accept_rate ~ decode_ratio - 1, which is roughly true
for spec-dec under stable acceptance conditions.
