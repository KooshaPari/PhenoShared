# Editorial Print

Define trim, bleed, safe area, binding/fold constraints, target substrate and the actual printer/vendor specification before choosing a template. For digital editorial work, define navigation, reading order and reflow expectations separately. Illustrator and layout applications can be authoring tools; they are not substitutes for a production preflight.

Use semantic styles, a deliberate grid, optical alignment and correctly licensed type. Keep editable native sources and externally linked art under explicit ownership. A PDF can be a delivery artifact without being the editable master. Record RGB/CMYK/spot-color decisions and conversions; do not promise a display appearance equals printed color.

Build an inexpensive representative page/label/package before producing every variant. Check overset text, image effective resolution, missing links, small type, transparency, overprint, rich black and spot plates where applicable. A browser screenshot is not print proof.

Acceptance requires source reopening, export preflight against the requested profile and an actual-size or vendor proof when physical output matters. Do not fabricate certification for standards that were not tested. This pack includes workflow guidance, not a generated print-ready job for an unspecified vendor.
