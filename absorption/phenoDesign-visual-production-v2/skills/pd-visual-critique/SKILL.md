# Visual Critique

Begin with the intended viewer task and the strongest reasonable alternative. Inspect actual exported pixels and actual interactions rather than judging source code or a design description. Keep geometry, fidelity, aesthetics, usability and performance as separate axes.

Assess silhouette/composition, hierarchy/type, color/material, lighting/volume, motion choreography, input response, content specificity and finish at intended size. A technical canary deliberately made of simple shapes is not a high-quality character or brand illustration. A beautiful still does not prove the animation is coherent; inspect transitions, rests and interruptions.

Give each material finding a location/frame/state, observable defect, impact and proposed correction. Prioritize the few changes that improve the central idea rather than adding decorative noise. Compare before and after under the same viewport, camera, lighting and content. Record where subjective preference—not a broken requirement—is driving a decision.

Automated measurements and model critique help find regressions, but a fixed numeric score must not certify taste. Preserve uncertain and failed results. Stop polishing only after the actual brief and acceptance criteria are met, or identify the exact unresolved quality limitation without pretending an untested path is complete.
