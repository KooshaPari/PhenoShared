# Data Diagrams

Start from the actual entities, relationships, quantities and uncertainty. Separate a conceptual illustration from a data-backed chart. Preserve the data/query, units, labels and a source representation that can be regenerated. D3/SVG, graph-layout tools, Manim and Motion Canvas serve different communication jobs.

Choose a static readable arrangement first. Animate only a meaningful transition, causal step or interaction. Do not use 3D perspective to distort quantities or decorative motion that obscures comparison. For graphs, define node grouping, edge meanings, expansion limits and stable identities before styling.

For explanatory video, align narration, highlights and scene timing explicitly. Validate equations and labels independently from the animation script. Different frames may need different levels of detail; preserve context so viewers do not lose the object of explanation between shots.

Acceptance includes semantic/data correctness, unclipped labels, meaningful legend, readable mobile/export variants, accessible textual/table equivalents and interaction tests. Geometry screenshots alone cannot verify a chart's underlying numbers. Keep authored presentation annotations distinct from original evidence and allow the user to inspect the exact source of quantitative claims.
