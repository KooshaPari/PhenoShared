# Collected upstream skill versus external candidates

The kit includes **one literal upstream skill snapshot**, Anthropic's frontend-design, with its Apache license and blob identity. The 18 `fd3d-*` skills are newly authored workflow instructions. They are not represented as the original work of other maintainers.

These are selected alternatives, not a claim that more installed skills equals better taste. Start with art direction, Blender/export, one interaction controller and real browser review.

## Safe acquisition workflow

Resolve the official repository and an immutable commit; inspect the license and referenced helper files; fetch the smallest complete skill folder into a quarantine directory; inspect executable hooks/network behavior; hash it; then explicitly copy the approved files to the canonical skills owner. Do not execute a README's curl pipe, npx install, native binary or arbitrary MCP code as part of reading the resource.

If upstream examples are broken, record the observed defect and consult the actual repository tree. Do not invent a corrected install command and call it tested. No installation/download script for these third-party projects is hidden in this ZIP.
