# Upstream skills: acquire thoughtfully

The kit contains 26 new original skills plus the original kit's 18 skills and licensed Anthropic frontend-design snapshot. Keep that upstream skill's license with it. The guarded installer includes it in the canonical skills directory without changing its contents.

## Remotion

The official skills page currently exposes specialized guidance for creation, rendering, multimedia, captions, maps, interaction and related workflows. Use the official repository and the installed skills tool's help. The publisher documents this discovery/install route:

```sh
npx skills add remotion-dev/skills
```

Do not blindly run that as a privileged install in the main workspace: npx itself may fetch executable code. Inspect/pin the installer/repository using the organization's acquisition mechanism, confirm current terms, and scope the installed skills. The upstream repository's root metadata was inspected; no clear standalone top-level license file appeared in the listing, so this ZIP links it rather than redistributing its complete text.

## Rive

Use the official CLI agent guide and CLI-generated project instructions. Qualify installed `rive --help`, its local docs/schema, creation/verification/inspection/screenshot operations. A generated AGENTS.md may assist that project; never overwrite the user's root instructions blindly.

## Design craft and frontend testing

The original catalog retains Anthropic frontend-design, Impeccable, browser-testing resources and the 3D pipeline references. Acquire only the relevant tool/plugin. More overlapping instruction sets can make an agent less coherent; this package's medium router should select a small active subset per task.

## Trust

Upstream skills are third-party instructions. Review source/revision, network execution, permissions and output provenance. They cannot override the user's design intent or permit fabricated success evidence. No purchases/private uploads/system-wide permission changes are implied by installation guidance.
