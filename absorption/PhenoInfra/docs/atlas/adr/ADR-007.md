# ADR-007 — Product pairs and distinct Tracera seats

**Status:** Proposed in this package; not a fabricated accepted human decision.  
**Source:** INT-001 and carried prior constraints.  
**Date:** 2026-09-15.

## Context

More chats can increase conflicting interpretations.

## Decision proposal

Split product implementation from independent assurance and bound ten Tracera streams.

## Alternatives considered

Sovereign per-repo agents; ten parallel graph rewrites.

## Consequences and verification

Shared schemas and integration ownership need early agreement. Bind the decision to an actual subject/owner and verify through the associated requirements, work and native evidence. A document's existence is not a product implementation or governance transition.

## Reconsideration trigger

Adjust allocation using blocked work and real review/resource capacity.
