# ADR-012 — No new destructive migration authority

**Status:** Proposed in this package; not a fabricated accepted human decision.  
**Source:** INT-001 and carried prior constraints.  
**Date:** 2026-09-15.

## Context

This is an atlas/QA/package request.

## Decision proposal

Preserve data and require separate scoped approval for source moves, admin merges, publication and retirement.

## Alternatives considered

Auto-clean based on counts or static references.

## Consequences and verification

Some lifecycle outcomes remain blocked for authorized actors. Bind the decision to an actual subject/owner and verify through the associated requirements, work and native evidence. A document's existence is not a product implementation or governance transition.

## Reconsideration trigger

Only explicit scoped human change can revise authority.
