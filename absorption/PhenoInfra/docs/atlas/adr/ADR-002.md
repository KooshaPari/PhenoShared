# ADR-002 — Every-span accountability without prose inflation

**Status:** Proposed in this package; not a fabricated accepted human decision.  
**Source:** INT-001 and carried prior constraints.  
**Date:** 2026-09-15.

## Context

Line-by-line essays would duplicate syntax and obscure semantics.

## Decision proposal

Classify spans and map meaningful semantic units to rationale/contracts.

## Alternatives considered

One paragraph per line; only README-level narrative.

## Consequences and verification

Generated/vendor units inherit producer rationale; critical short spans remain deeply specified. Bind the decision to an actual subject/owner and verify through the associated requirements, work and native evidence. A document's existence is not a product implementation or governance transition.

## Reconsideration trigger

Reconsider granularity when maintainers cannot answer a real question.
