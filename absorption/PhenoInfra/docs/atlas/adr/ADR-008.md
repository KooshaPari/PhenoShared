# ADR-008 — Facts, claims and decisions remain separate

**Status:** Proposed in this package; not a fabricated accepted human decision.  
**Source:** INT-001 and carried prior constraints.  
**Date:** 2026-09-15.

## Context

A confident model summary can otherwise authorize harmful changes.

## Decision proposal

Retain observation provenance, uncertainty and scoped authority as separate records.

## Alternatives considered

Last-write-wins documents; repo prefixes as permission.

## Consequences and verification

More explicit status fields but safer automation. Bind the decision to an actual subject/owner and verify through the associated requirements, work and native evidence. A document's existence is not a product implementation or governance transition.

## Reconsideration trigger

Do not weaken because a command succeeded once.
