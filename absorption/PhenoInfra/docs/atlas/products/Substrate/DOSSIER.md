## 5. Controlled pilot

Benchmark two distinct workloads rather than a composite score. Model traffic: stream, failover, cancel and account. Process dispatch: spawn, observe, fail, restart and terminate actual tools under explicit scopes. Compare each with the simplest appropriate existing implementation.

Use fixed versioned inputs and independent outcome oracles. Run matched conditions to isolate mechanisms and a separate idiomatic implementation to compare practical products. Retain failed attempts, intervention logs and infrastructure outcomes. Assign confidence intervals or explicit uncertainty; do not infer a universal winner from one run.

Failure and negative-control cases:

- Model retry rules incorrectly applied to side-effecting processes
- Cancellation loses ownership
- Output crosses tenants
- Timeout hides a still-running child
- Duplicate provider registry diverges
