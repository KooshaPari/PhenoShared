# Traceability

The machine source is `records/traceability.json`. It links captured intent → proposed program requirements → provisional feature bundles → proposed work packages → acceptance. Product test/evidence edges are intentionally empty until actual execution. Missing proof is not synthetic completion.

Product dossiers and pilots are linked by stable product IDs; the original 62-ID audit remains contextual. Per-product source/executable/test links must be extracted locally. A broad program requirement cannot substitute for the thousands of genuine product-level entities that may emerge.

The package validator checks unique IDs, non-orphan requirement links, task dependencies and required artifact references. It does not prove semantic completeness or factual correctness of every future graph edge.
