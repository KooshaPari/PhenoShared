# Reading edition

ATLAS-ASSURANCE-PROGRAM.pdf is a 33-page programmatic reading edition of the package method and all 23 product plans, plus pooled/supporting obligations. Editable normative/planning material remains in the Markdown and JSON sources.

Regenerate using `python scripts/render_report.py` from the docs root with the optional reportlab dependency. Report content is generated from the product records and curated operating summary. This PDF is not a fresh audit or product benchmark.
