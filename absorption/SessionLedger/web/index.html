Session event capture, made boring

sl-daemon tails JSONL files, compiles them, exports OKF bundles. sl-viewer renders them. No database required.

Worker pool ETL

tokio-based consumer pool with worker count from 1 to N. Bounded channels for back-pressure.

Plugin system

IngestionAdapter, Exporter, and Port traits. Built-in JSONL ingester + CSV exporter + in-memory port.

use sl_daemon::plugin::default_registry;
let r = default_registry();

OKF bundles

Self-describing envelope with reproducible compression and traceparent sidecars.

Dioxus desktop viewer

Native desktop viewer (sl-viewer) renders OKF bundles into a navigable UI.
