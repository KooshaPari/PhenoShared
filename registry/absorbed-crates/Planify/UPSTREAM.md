# Upstream Seeding

Planify is a fork of [Plane](https://github.com/makeplane/plane), the open-source project management platform.

## To seed this repo from upstream:

```bash
git remote add upstream https://github.com/makeplane/plane
git pull upstream main
git push origin main
```

## Purpose

Planify will serve as the Phenotype PM web frontend, powering the AgilePlus dashboard UI. It derives from Plane but may contain Phenotype-specific customizations and integrations.

## Related

- **AgilePlus**: Rust backend PM substrate
- **phenotype.space**: Phenotype platform hub
