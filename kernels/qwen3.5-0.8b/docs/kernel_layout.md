## Architecture constants

Source of truth: `arch.yaml`. The codegen pipeline
(`python/codegen.py`) emits these constants to every language binding
under `include/`, `rust/src/`, `zig/`, `mojo/`, `nim/`, plus the
canonical JSON dump under `codegen/arch.json`.

| Constant | Value | Notes |
|----------|-------|-------|
| `hidden_size` | 1024 | per-layer hidden dim |
| `intermediate_size` | 3584 | SwiGLU intermediate |
| `num_hidden_layers` | 24 | 6 full-attn + 18 DeltaNet linear |
| `vocab_size` | 248320 | tied embeddings |
| `head_dim` | 256 | full-attn head |
| `GQA ratio` | 4:1 | 8 Q heads / 2 KV heads |
| `M-RoPE` | [11, 11, 10] | T/H/W sections (32 = 0.25 × head_dim) |
| `partial_rotary_factor` | 0.25 | only 25% of head_dim is rope-rotated |

## Audit-A4 close-out — kArchSimdgroupSize

The audit-A4 follow-up binds the runtime simdgroup size at the host
boundary via `MTLFunctionConstantValues` at pipeline-creation time. The
canonical constant lives in `iso/hybrid_decode_dispatch.inc`:

```metal
constant uint kArchSimdgroupSize = 32u;
```

This is sourced from `arch.yaml.kernel_strategy.default_simdgroup_size`
which is 32 for Apple Silicon (M1/M2/M3/M4). The dispatch include
is auto-generated by the codegen pipeline; drift between `arch.yaml`
and the Metal include is caught by `tests/test_metal_simdgroup_constant.py`
in 3 fixtures:

1. `arch.yaml` is the single source of truth.
2. The generated `arch.json` (when `kernel_strategy` is emitted by
   `codegen.py`) agrees.
3. The C header / dispatch include carries the constant under a
   stable name.

### Codegen gap (DAG-41)

The current `python/codegen.py` does **not** yet emit
`kernel_strategy` to `arch.json` or to the per-language bindings. The
constant propagates only via the `iso/hybrid_decode_dispatch.inc` path
(which is hand-emitted + drift-guarded). DAG-41 will extend the
codegen to emit:

  - `kernel_strategy.default_simdgroup_size` → `arch.json`
  - `kernel_strategy.threadgroup_size_default` → `arch.json`
  - `QWEN3_5_SIMDGROUP_SIZE` (C macro) → `include/qwen3_5.h`
  - `kArchSimdgroupSize` (Rust const) → `rust/src/arch.rs`
  - `kArchSimdgroupSize` (Zig comptime) → `zig/qwen3_5.zig`
  - `kArchSimdgroupSize` (Mojo comptime) → `mojo/qwen3_5.mojo`
  - `kArchSimdgroupSize` (Nim const) → `nim/qwen3_5.nim`

Until DAG-41 lands, the host binding at runtime is the load-bearing
guarantee — see `tests/test_metal_simdgroup_constant.py` for the
drift-guard.

## Per-op kernel strategy

| Op | Kernel | Why |
|----|--------|-----|
| `rmsnorm` | `fused_ssm_rmsnorm` | input + residual + norm in one pass |
| `rope` | `mrope_partial_interleaved` | partial rotary (0.25), mrope_section |
| `qkv_proj` | `fused_linear_bf16` | one GEMM, then split Q/K/V |
| `ffn_up_gate` | `fused_swiglu_pack` | gate,up,down packed + on-the-fly silu |
| `full_attention` | `flash_attn_v2_gqa` | flash-attn 2 with GQA 4:1 broadcast |
| `linear_attention` | `deltanet_v1` | gated delta-rule recurrent |
| `attn_output_gate` | `sigmoid_gate` | sigmoid(out_proj * o_gate) |
| `sampling` | `fused_topk_topp_argmax` | single-pass greedy / temperature / topk / topp |
| `embedding` | `gather_bf16` | tied with lm_head |
| `lm_head` | `matmul_bf16` | hidden @ embed.T |

## Hybrid layer schedule

24 layers, every 4th is full attention (layers 3, 7, 11, 15, 19, 23):

```
[L, L, L, F, L, L, L, F, L, L, L, F, L, L, L, F, L, L, L, F, L, L, L, F]
```

`full_count = 6`, `linear_count = 18`. The schedule is encoded in
`arch.yaml.layer_types.schedule` and emitted as
`kHybridFullAttnLayerIndices` in the dispatch include.
