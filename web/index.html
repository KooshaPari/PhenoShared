Deterministic eval, pluggable everything

pheno-harness provides RLVR/Harbor operator wrappers, a plugin system, and a typed registry for benchmark suites, tasks, and metrics.

Bench plugin system

Custom judges, contracts, and adapters register as Python plugins with hook handlers.

from bench.plugin import Plugin, default_registry

class TimingPlugin(Plugin):
    name = "timing"
    @self.hook("post_metric")
    def record(task, metrics): ...

Suite registry

Suites auto-register via __init_subclass__. Task specs persist class-level metadata for the runner.

Adapters for Anthropic / OpenAI / MLX

Common interface with feature flags for MLX on Apple Silicon and mock fixtures for CI.

Replay contract

Record and rehydrate Envelope bundles. Streamlit UI for diff and replay.
